The smoke model requires 13-band uint16 imagery (90–120 px per side). RGB, PNG/JPEG, four-band chips, or unknown band order are not passed to it. If band descriptions are absent, confirm the actual source order before analysis.

Without a compatible 13-band GeoTIFF, the image is previewed but smoke inference does not run.
